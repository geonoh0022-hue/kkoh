수행평가 관리 · 무료 배포 시작하기

기존 채점 기능에 로그인, 서버 저장, 전체 백업과 복원을 추가한 앱입니다.

무료 계정 3개가 필요합니다.
GitHub는 코드, Render는 앱 화면, Supabase는 로그인과 자료를 보관합니다. Render 무료 데이터베이스는 30일 후 만료되므로 사용하지 않습니다. 무료 서비스의 영구 제공은 보장할 수 없습니다. 이 ZIP과 전체 JSON 백업을 보관하면 서비스가 없어져도 오프라인으로 이어서 사용할 수 있습니다.

1. 우선 내 컴퓨터에서 열어보기

오프라인-실행.html 열기. 프로그램 설치 없이 브라우저에서 실행됩니다. 기존 자료는 원래 파일의 ‘기존 자료 전체 백업’으로 내려받고 새 앱의 ‘전체 백업 가져오기’로 옮기세요. 엑셀 파일은 전체 복원용이 아닙니다.

2. Supabase 무료 저장소 만들기

  1. Supabase에서 Free 플랜으로 프로젝트를 만듭니다. 유료 플랜으로 전환하지 않습니다.
  2. SQL Editor → New query에서 ZIP의 schema.sql 전체 내용을 붙여 넣고 실행합니다.
  3. Authentication → Users에서 본인 이메일과 비밀번호로 사용자를 직접 추가합니다. 자동 이메일 확인 옵션으로 확인 처리하고 공개 회원가입은 끕니다. 메뉴 이름은 바뀔 수 있습니다.
  4. 프로젝트의 Connect 또는 설정 화면에서 Project URL과 Publishable key(또는 기존 anon key)를 복사해 둡니다. secret/service_role 키는 사용하지 않습니다.

3. GitHub에 코드 보관하기

  1. GitHub에서 Private 저장소를 만듭니다.
  2. Add file → Upload files로 ZIP을 푼 폴더의 내용을 올립니다. ZIP 자체를 올리지 말고, public 폴더가 그대로 보이도록 폴더째 드래그하세요.
  3. 저장소 첫 화면에 public, schema.sql, render.yaml, README.md 등이 보이면 됩니다. 학생 자료, 비밀번호, 개인 JSON 백업은 올리지 마세요.

4. Render에 무료 앱 게시하기

  1. Render에서 New → Static Site를 선택하고 GitHub 저장소를 연결합니다.
  2. Build Command: echo static-files-ready
    Publish Directory: public
    Root Directory는 비워 둡니다.
  3. 생성을 완료하고 발급된 onrender.com 주소를 엽니다. Web Service, Postgres, 유료 디스크, 유료 도메인은 필요하지 않습니다.

5. 서버 저장 시작하기

  1. 앱 위쪽 ‘무료 서버 설정 / 로그인’을 펼칩니다. Supabase URL, 공개 키, 앞서 만든 이메일/비밀번호를 입력합니다.
  2. 기존 JSON 백업을 가져옵니다. 서버가 비어 있으면 ‘현재 자료 첫 저장’을 누릅니다.
  3. 서버 저장 완료 표시를 확인합니다. 이후 변경은 자동 저장됩니다.
  4. 다른 기기에서는 같은 설정으로 로그인하고 ‘서버 자료 불러오기’를 누릅니다. 새로고침 후에도 다시 로그인해야 합니다.

오래 쓰기 위한 보관 습관

  • 매주·학기 마감 시 전체 백업 내려받기를 누르고 컴퓨터와 별도 저장장치에 보관하세요. 서버에는 최신 자료만 있으며 과거 버전 자동 백업 기능은 없습니다.
  • Supabase Free는 약 1주간 사용이 없으면 일시정지될 수 있습니다. 연결이 안 되면 대시보드에서 프로젝트 상태와 복구 가능 여부를 확인하세요.
  • 인터넷 오류 시 자료는 브라우저에 남습니다. 백업을 먼저 받고 ‘저장 재시도’를 누르세요.
  • 충돌이 나면 양쪽 자료를 백업하고 비교하세요. 서버 불러오기와 백업 가져오기는 전체 교체이며 자동 병합은 아닙니다.
  • 서비스 중단 시 오프라인 실행본에 마지막 백업을 가져오세요. 새 무료 저장소를 만들면 같은 방식으로 이전할 수 있습니다.

실제 계정 연결과 배포는 사용자가 위 순서로 진행해야 합니다. 이 패키지는 브라우저 기능과 모의 서버 통신을 검증했으며, 실제 Supabase SQL/RLS 및 Render 배포 검증은 아직 하지 않았습니다. 먼저 가상 학생으로 저장·복원과 다른 계정의 접근 차단을 확인하세요.
